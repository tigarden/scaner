# 🐶👤 VisionAI: Детектор «Человек или Собака»

Мобильное веб-приложение (PWA) для смартфонов, которое в реальном времени через камеру распознает человека и/или собаку с помощью нейросети **TensorFlow.js** и модели **COCO-SSD**.

## 🌟 Особенности
- 🚀 **100% On-Device:** нейросеть выполняется прямо в браузере мобильного телефона без отправки кадров на сервер.
- 📱 **PWA (Progressive Web App):** приложение адаптировано под экраны мобильных телефонов и может быть установлено на главный экран как нативное.
- 🎯 **Высокая точность:** выделение рамок (bounding boxes) с процентом уверенности модели.
- 🔄 **Переключение камеры:** поддержка как задней (основной), так и фронтальной (селфи) камеры.
- 🔊 **Озвучка и тактильный отклик:** синтез речи на русском языке и вибрация смартфона при обнаружении цели.
- 📸 **Снимок с детекцией:** кнопка для мгновенного сохранения кадра с наложенными метками нейросети.

## 🛠 Технологии
- HTML5 / CSS3 (Glassmorphism UI, Mobile-first)
- JavaScript (ES6+, WebRTC `getUserMedia`)
- [TensorFlow.js](https://www.tensorflow.org/js)
- [COCO-SSD](https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd) (MobileNet v2 lite)
- Service Worker & Web App Manifest
